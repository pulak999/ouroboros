- **12** are **MIG configuration**, reachable by ioctl. This is
  the set that reshapes the GPU.
- **12** are **MIG-aware runtime queries**, reachable by ioctl.

## How to read this

Three independent sources are combined:

- **static** — name, class and header in the vendored 610.43.02 SDK.
- **driver** — measured against the loaded 555.42.02 binary with
  `sweep_controls --size-scan`. `present` means the command is in the
  driver's NVOC export table. `present, hw n/a` means the driver has it
  but the handler answers `NV_ERR_NOT_SUPPORTED` on this GPU, which is
  what a non-MIG card does. `absent` means this driver does not have it.
- **observed** — the command appears in a real capture under `sniffed/`.

`driver size` is the paramsSize the shipped driver actually enforces,
recovered by scan. Where it differs from `hdr size`, **trust the driver**
column: the 610 headers do not describe the 555 binary.
